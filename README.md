Ember Pact — a turn-based duel of cards against Rook, the Thorn Keeper. First to 0 life loses. Each round you gain ember and draw a card; play damage, Block or healing cards, chain two cards of one suit for Resonance +2, and read Rook's telegraphed intent to counter it.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network requests, all files under game/.
